🎯 Number Guessing Game

A simple Python Number Guessing Game for beginners.

The computer randomly chooses a number between 1 and 20, and the player tries to guess it.

🧩 How It Works

1. The program generates a random number from 1 to 20.
2. The player enters a guess.
3. The program checks whether the guess matches the random number.
4. If the guess is correct, you win! 🎉
5. If the guess is wrong, the program says "Try Again!"
6. The "while True" loop keeps the game running continuously.

🛠️ Concepts Used

This project demonstrates some basic Python concepts:

- "while" loop
- "if / else" statements
- "random" module
- "random.randint()"
- "input()"
- "int()"
- Variables
- Comparison operators

⚠️ Important Note

Because the program uses:

while True:

the game never stops on its own.

To stop the program, press:

Ctrl + C
